# Course 6 - Sound the Alarm: Detection and Response

Google Cybersecurity Professional Certificate

## Overview
In this course, I learned how cybersecurity teams detect and respond to security incidents. It covers how alerts are investigated, how incidents are contained, and how to use tools like SIEM and network monitoring to protect an organization.

## What I Learned
- How to detect security incidents using alerts, logs, and SIEM tools
- The incident response lifecycle: Preparation, Detection, Containment, Eradication, Recovery, and Post-Incident Activity
- How to analyze network traffic using Wireshark, tcpdump, and Suricata
- How to use Splunk and Chronicle to investigate security events
- How to follow incident response playbooks and document incidents

## Skills Gained
- Incident Response
- Intrusion Detection
- Network Traffic Analysis
- SIEM (Splunk, Chronicle)
- Log Analysis
- Incident Documentation
